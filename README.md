## Quick run tips

- For **Python** projects, look for `requirements.txt` and run in a virtual environment.
- For **C/C++** projects, look for a `Makefile` (common commands: `make`, `make clean`).
- For **Java** projects, open the folder in an IDE (IntelliJ/Eclipse) or look for build instructions inside the folder.

## Notes
- Many folders contain **assignment specs and PDFs**; code-run instructions (when available) live inside the project folder.
- Some projects are best reviewed by opening the **report / PDF** first, then skimming the code.
