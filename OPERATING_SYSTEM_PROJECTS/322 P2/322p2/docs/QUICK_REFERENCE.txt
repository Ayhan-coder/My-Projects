┌─ IMPLEMENTED FUNCTIONS ───────────────────────────────────────────────────┐
│                                                                            │
│  1. int array_allocation()                                                 │
│     - Allocates hash_array, entry_list, lock_list                         │
│     - Initializes all mutexes                                              │
│                                                                            │
│  2. int array_deallocation()                                               │
│     - Destroys all mutexes                                                 │
│     - Frees all allocated memory                                           │
│                                                                            │
│  3. int sequential_h_1()                                                   │
│     - Sequential hash with h(i) = (i+c) mod n                             │
│     - Linear probing on collision                                          │
│                                                                            │
│  4. int parallel_h_1()                                                     │
│     - Parallel version with t threads                                      │
│     - Uses trylock for non-blocking                                        │
│     - Optimized for speedup                                                │
│                                                                            │
│  5. int parallel_h_2()                                                     │
│     - Window-based hashing (n/k windows)                                   │
│     - Acquires all locks before checking                                   │
│     - Releases all on failure (deadlock prevention)                        │
│                                                                            │
│  6. int speedup_comparison_h_1()                                           │
│     - Measures sequential vs parallel time                                 │
│     - Sets h_1_speedup = sequential_time / parallel_time                   │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ KEY ALGORITHMS ──────────────────────────────────────────────────────────┐
│                                                                            │
│  H_1 Hash Function:                                                        │
│    h_1(i) = (i + c) mod n                                                  │
│    - Linear probing: try positions i, i+1, i+2, ... until empty            │
│                                                                            │
│  H_2 Hash Function:                                                        │
│    h_2(i) = ((i + c) mod k) + z*k,  where z ∈ {0, 1, ..., (n/k)-1}       │
│    - Divides array into n/k windows of size k                             │
│    - Tries same relative position in all windows                           │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ THREAD DISTRIBUTION ─────────────────────────────────────────────────────┐
│                                                                            │
│  m entries divided among t threads:                                        │
│    Thread 0: entries [0 ... m/t-1]                                         │
│    Thread 1: entries [m/t ... 2*m/t-1]                                     │
│    Thread i: entries [i*m/t ... (i+1)*m/t-1]                               │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ DEADLOCK PREVENTION (h_2) ───────────────────────────────────────────────┐
│                                                                            │
│  Strategy: Release all acquired locks if any acquisition fails             │
│                                                                            │
│  for each window:                                                          │
│      if trylock fails:                                                     │
│          release ALL previously acquired locks                             │
│          retry from beginning                                              │
│                                                                            │
│  NO sleep(), NO wait(), NO timeouts - just release and retry!              │
│                                                                            │
└────────────────────────────────────────────────────────────────────────────┘

┌─ TIMESTAMP RECORDING ─────────────────────────────────────────────────────┐
│                                                                            │
│  When: Immediately after placing entry in hash_array                       │
│  How:  clock_gettime(CLOCK_MONOTONIC, &ts)                                 │
│  Store: (ts.tv_sec * 1000000000LL + ts.tv_nsec) as int64_t               │
│                                                                            │
│  Example:                                                                  │
│    struct timespec ts;                                                     │
│    clock_gettime(CLOCK_MONOTONIC, &ts);                                    │
│    entry.timestamp = ts.tv_sec * 1000000000LL + ts.tv_nsec;               │
